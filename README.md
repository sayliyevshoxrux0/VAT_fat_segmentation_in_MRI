# VAT Fat Segmentation in MRI

Research code and exported results for VAT (visceral adipose tissue) segmentation in MRI using pseudo-labels and expert masks.

## Setup

Use Python 3. Install the pinned dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Place authorized MRI data under `data/` following [data/README_DATA.md](data/README_DATA.md). Model checkpoints are not included; see [weights/README_WEIGHTS.md](weights/README_WEIGHTS.md).

## Available scripts

Run commands from this project directory so the relative `data/`, `weights/`, `results/`, and `figures/` paths resolve:

```powershell
python src\train.py
python src\export_per_patient.py
python src\calculate_bootstrap.py
python src\check.py
```

- `src/train.py` trains a U-Net with a selectable SMP encoder (currently configured for `mit_b0`), BCE plus soft Dice loss, and expert validation checkpointing. It uses the fuzzy C-means training masks and writes checkpoints to `weights/fuzzy_means/`. Training currently requires CUDA; the evaluation scripts select CUDA when available and otherwise use CPU.
- `src/dataset.py` loads images and masks; `src/noise_generator.py` provides the morphological mask noise used during training.
- `src/expert_eval_loaders.py` creates validation and test loaders from expert masks.
- `src/models.py` builds one-channel U-Net models with the requested encoder.
- `src/export_per_patient.py` evaluates available checkpoints against the expert test masks and writes `results/per_patient_test_dice.csv`.
- `src/calculate_bootstrap.py` computes 95% bootstrap intervals from that per-patient CSV.
- `src/check.py` performs quantitative Grad-CAM analysis; it expects the checkpoints named in the script under `weights/`.

The preprocessing, Otsu/K-means/Fuzzy C-means label-generation, aggregate evaluation, and Grad-CAM visualization-generation scripts from the proposed layout are not present in this checkout. The figures and CSV files currently in the repository are existing exports, not generated by these commands.

## Repository layout

- `src/`: available Python source.
- `figures/`: existing plots and comparison images.
- `results/`: existing CSV metrics and analysis outputs.
- `data/`: ignored MRI inputs; only its usage instructions are tracked.
- `weights/`: ignored model checkpoints; only its usage instructions are tracked.
